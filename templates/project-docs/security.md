# Security

## Назначение

Опишите security boundaries и правила безопасных изменений.

## Аутентификация И Авторизация

Опишите модели пользователей, ролей, прав и сервисных доступов.

## Секреты

Опишите, где хранятся секреты, как они ротируются и какие файлы нельзя коммитить.

## Поверхность Атаки

Опишите публичные endpoints, admin surfaces, webhooks, integrations и trusted boundaries.

## Проверки

Опишите security checks перед релизом: dependencies, permissions, input validation, logging redaction.
