Этот стандарт задает постоянные правила организации документации AI Docs Hub. Его цель - минимальный релевантный контекст для каждой задачи, а не минимальное количество файлов или строк.

## Когда Нужна Реорганизация

Документ является кандидатом на реорганизацию, если выполняется хотя бы одно условие:

- он объединяет несколько независимо используемых предметных областей;
- агенту обычно нужна только небольшая часть документа;
- он одновременно смешивает reference, runbook, policy, history или agent instructions;
- значительная часть текста дублирует другой canonical source;
- документ содержит устаревшее состояние проекта;
- дальнейшее добавление разделов ухудшает точность AI retrieval.

Размер более примерно 200-300 строк или 15-25 KB является сигналом для проверки, но не автоматическим основанием для дробления.

## Канонические Источники

- Один факт или контракт должен иметь один canonical source.
- `AGENTS.md` содержит только глобальные guardrails и маршрутизацию.
- Agent workflow хранится в `.agents/skills/`.
- Product-, architecture-, UI- и runtime-контракты хранятся в `docs/`.
- Исторические решения выносятся из current reference, если имеют самостоятельную ценность.
- При противоречии документации и кода актуальный код используется как source of truth для текущего поведения; конфликт нужно явно зафиксировать и устранить в рамках изменения.

## Retrieval И Навигация

После реорганизации документации нужно проверить и при необходимости обновить:

- ссылки между документами;
- MkDocs navigation подключенного проекта;
- индекс AI Docs Hub;
- generated `llms*.txt`.

При существенном изменении документации дополнительно проверяйте, не пора ли существующий документ разделить или, наоборот, объединить с другим. Новая структура не должна создавать дублирующиеся описания одного контракта.

## Обязанность Проверки

До завершения изменения нужно проверить, что агент может найти правило по узкой релевантной выборке, а не только через большой смешанный документ. Если документация и код расходятся, укажите оба пути, проверьте актуальный код и обновите canonical source.
