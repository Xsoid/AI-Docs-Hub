# Документация AI Docs Hub

Этот каталог содержит единственные канонические документы самого Hub. Он не содержит копии документации подключенных проектов.

| Раздел | Назначение |
| --- | --- |
| `architecture/` | Фактическая архитектура и границы системы. |
| `standards/` | Действующие политики и контракты. |
| `operations/` | Выполнимые процедуры, команды и результаты проверок. |
| `decisions/` | ADR и последовательность замещения решений. |
| `changes/` | Неизменяемая смысловая история изменений. |

Начните с [обзора архитектуры](architecture/overview.md). Для команд используйте [справочник операций](operations/command-reference.md). Для правил владения документами используйте [стандарт гигиены](standards/documentation-hygiene.md). Для языка инструкций используйте [стиль технического письма](standards/technical-writing.md).

Сайт документации отображает канонические документы через генератор. Его site-only страницы дают навигацию и не являются вторым источником правил.
