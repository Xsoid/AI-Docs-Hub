# 0002: Генерировать Канонические Страницы Docs-Site Из `docs/`

Дата: 2026-10-15

Статус: Accepted

Заменяет: часть follow-up в [ADR 0001](0001-use-docs-directory-for-hub-documentation.md).

## Контекст

ADR 0001 установил `docs/` как источник документации Hub. Он оставил открытым способ представления этих документов в docs-site. Ручные зеркальные страницы создали риск расхождения.

## Решение

`scripts/generate-hub-pages` рендерит architecture, operations и standards из `docs/` в ignored страницы docs-site. Страница с generated marker не имеет второго редактируемого источника.

Tracked site-only страницы сохраняют публичные маршруты. Они содержат только навигацию и краткое назначение. Они ссылаются на канонический документ для правила или процедуры.

## Последствия

Изменение канонического Hub-документа требует `make hub-pages`. Генератор останавливается до коллизии путей или перезаписи ручной страницы. Он удаляет только obsolete output с собственным marker в managed directories.
