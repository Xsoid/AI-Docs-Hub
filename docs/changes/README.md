# Заметки Об Изменениях

Эта директория фиксирует значимые изменения AI Docs Hub в человекочитаемой форме.

Используйте один файл на изменение или небольшую связанную пачку изменений.

Рекомендуемое имя файла:

```text
YYYY-MM-DD-short-topic.md
```

Каждая заметка должна объяснять:

- что изменилось;
- почему это изменилось;
- как это влияет на эксплуатацию или сопровождение;
- что было проверено;
- какой follow-up остается.
