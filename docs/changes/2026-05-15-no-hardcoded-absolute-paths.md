# 2026-05-15: Убраны Hard-Coded Абсолютные Пути

## Кратко

Архитектура хаба переведена на переносимые пути в source-файлах.

## Что Изменилось

- Project configs могут использовать `${AI_DOCS_PROJECTS_ROOT}/project-name`.
- По умолчанию `${AI_DOCS_PROJECTS_ROOT}` разворачивается в родительскую директорию checkout хаба.
- Шаблоны используют placeholder-ы вместо путей конкретной машины.
- Menu bar helper больше не запускает статус через зашитый путь к runtime.
- README и `/docs` описывают правило: в source-документации и архитектуре не должно быть hard-coded абсолютных путей.

## Поведение

Runtime по-прежнему работает с реальными путями после разрешения переменных и относительных путей. Это нужно для индексации внешних проектов и запуска процессов.

Source-of-truth при этом остается переносимым. Host-specific абсолютные пути допустимы только в runtime-generated файлах вне репозитория, например в установленном plist `launchd`.

## Проверка

Проверено:

- повторный поиск hard-coded путей по source-файлам;
- `make validate-configs`;
- `make healthcheck`;
- пересборка menu bar app.
