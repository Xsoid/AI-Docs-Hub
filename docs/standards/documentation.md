# Стандарт Документации

Этот стандарт определяет, где хранить документацию Hub. Правила владения, generated-артефактов и языка находятся в отдельных канонических документах:

- [Гигиена документации](documentation-hygiene.md) определяет владельца каждого вида документа и правила консолидации.
- [Generated-артефакты](generated-artifacts.md) определяют, что можно редактировать вручную и что создают генераторы.
- [Техническое письмо](technical-writing.md) определяет Controlled Technical Russian и ASD-STE100-aware English.
- [Справочник команд](../operations/command-reference.md) определяет выполняемые команды.

Не повторяйте правила из этих документов. Ссылайтесь на их раздел, если правило требуется в другом контексте.
